# 🔥 Algerian Forest Fire Prediction

A Machine Learning web application built using Flask and Scikit-learn to predict the Fire Weather Index (FWI) for the Algerian Forest Fire dataset.

## 🚀 Features

- Predicts Fire Weather Index (FWI)
- Flask Web Application
- Ridge Regression Model
- StandardScaler for preprocessing
- HTML frontend

## 🛠️ Technologies Used

- Python
- Flask
- Scikit-learn
- Pandas
- NumPy
- HTML
